# Genesis

Single-page landing site for **Genesis**, a 3-person tech agency in Athens, Greece.

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```

## Sections

- Hero
- What we build
- Work / portfolio
- Team
- Contact

## Deploy

Connected to Vercel from the `main` branch.
